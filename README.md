# ADB 安装器（AdbInstaller）

电视 / 机顶盒上的 APK 安装器：**不用电脑、不用 U 盘**，靠内置 `adb` 自己给自己装应用。

> 本仓库只发布安装包（Release），不提供源码。

## 下载

到 [Releases](https://github.com/orVC/AdbInstaller/releases/latest) 下载最新的 `adb-install-vX.Y.apk`。

## 安装与首次使用

1. 把 APK 装到电视（U 盘、或用另一台装了本应用/任意 adb 工具的机器推送）；
2. 电视打开「开发者选项 → USB 调试 / 网络调试」（小米电视：设置 → 关于 → 连点版本号开启开发者选项）；
3. 打开应用 →「设置」→ 点「获取本机 ADB 权限」；
4. 电视弹「允许 USB 调试吗」时勾选**始终允许** → 确定，**然后再点一次按钮**；
5. 状态变绿后，到「文件目录」选中 APK 即可安装。

## 四个页签

| 页签 | 作用 |
| --- | --- |
| 设置 | 目标地址 + 获取本机 ADB 权限（内置 ARM32 adb，连 `127.0.0.1:5555`） |
| 搜索设备 | 扫描局域网 `1–254` 的 `5555` 端口，点一下即连接该设备（手机给电视装就靠它） |
| 文件目录 | 内置文件浏览器（不依赖系统 DocumentsUI），选中 APK 直接 adb 安装 |
| 推送文件 | 手机扫码/浏览器上传到 `/sdcard/AdbInstaller`（默认端口 56789，被占用自动顺延） |

## 手机给电视装（推荐组合用法）

手机装同一个 APK → 连同一 WiFi →「搜索设备」扫到电视 `IP:5555` → 点它 → 电视上点「始终允许」→ 手机「文件目录」选 APK → 自动装到电视。

## 常见问题

- **提示「没有可执行此操作的应用」**：老版本依赖系统文件选择器，现在内置文件浏览器，不会再出现。
- **一直 unauthorized**：电视上点「允许」后要**再点一次按钮**（应用会自动断开重连握手）。
- **提示「无法执行内置 adb」**：内置 adb 是 ARM32；纯 64 位用户空间的设备需要换 aarch64 版。
- **手机扫码打不开**：手机和电视必须在同一网段、同一路由器，且没开「AP 隔离」。
- **Android 13/14 列不出目录**：确保应用有存储权限（本应用 targetSdk 28，仍用旧权限模型）。

## 说明

- 系统要求：Android 5.1+（minSdk 21，targetSdk 28）。
- 应用不申请 root，也不向任何服务器上传数据；网络行为仅限你的局域网。
- 请只安装你信任的 APK；使用本工具造成的后果由使用者自行承担。
